# Projects

One directory per object. Create them with `.agents/tools/cad new <name>`;
names are lowercase with hyphens.

```
projects/<name>/
  README.md     the brief: requirements, dimension table with sources,
                assumptions, design decisions, changelog
  spec.yaml     material, export formats, machine-checkable acceptance checks
  model.py      build123d model; build() returns a Shape or {name: Shape}
  reference/    photos, sketches, datasheets supplied by the user (committed)
  output/       generated, not committed:
                  <name>.step / .stl / .3mf   exported geometry
                  report.json                 all measurements and check results
                  preview/<name>_views.png    four rendered views in one image
                  preview/<name>_<view>.svg   2D drawings with hidden lines
```

`output/` is regenerated by `.agents/tools/cad build <name>` and is listed in
`.gitignore`. Everything else is committed, so a project can be rebuilt and
reviewed from the repository alone.
